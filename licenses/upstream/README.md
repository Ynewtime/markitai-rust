# Exact-version upstream license evidence

These local files supplement Cargo packages whose published source did not contain license text. Packaging reads them offline. The manifest anchors each crate to its published VCS commit and original Cargo manifest, records exact official URLs and SHA-256 hashes, and separates complete text from notices.

Six crate versions have at least one complete license option; eight objc2-family crate versions and selectors have notices only and remain unresolved for full license text. Nothing here elects an alternative, substitutes a standard template, or constitutes legal review. In particular, objc2-family Apple SDK notices are retained without interpretation.

The sixteen overlay files preserve upstream bytes. The selectors MPL notice is an explicitly bounded prefix of the retained source file; other files are complete source files. Raw HTTP outcome records retain the stale objc2-encode LICENSE.txt 404. Directory browsing snapshots remain in the collection evidence outside this shipped subset; complete package/version attribution rests on the exact matching manifests and VCS records included here.

`inventory.json` covers every other file under this directory. Its hashes detect accidental or unreviewed content changes before packaging; the checkout/build identity protects the inventory itself. The generated package includes this entire evidence subset, not just the license text.
